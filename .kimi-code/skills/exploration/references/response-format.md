# Формат итогового отчёта разведки

```markdown
## Разведка: <название модуля/пакета>

**Назначение:** одна фраза — что это и зачем.

**Технологии:** Java <версия>, Spring Boot <версия из parent-pom>, Maven.

**Точки входа:**
- `<путь>:<класс>#main` — что запускает

**Структура:**
- `<пакет>/` — роль пакета (service, config, excluded...)

**Ключевые механики Spring:**
- `<аннотация/класс>` в `<файл>` — какую механику демонстрирует

**Зависимости:**
- `<artifactId>` (scope) — зачем нужен

**Наблюдения:**
- неочевидные детали, подводные камни, что стоит смотреть в дебаге первым
```

Правила отчёта: каждый вывод — с путём к файлу-доказательству; не более одной страницы; раздел «Наблюдения» — самый ценный, не пропускать.
