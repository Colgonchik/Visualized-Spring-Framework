# Чек-лист верификации модуля Visual SB

## Сборка и тесты

- [ ] `mvn test` из корня репозитория — зелёное (все модули, не только изменённый)
- [ ] `mvn spring-boot:run` конкретного модуля — приложение стартует и завершается штатно
- [ ] Ожидаемый вывод из README модуля совпадает с реальным побайтово (имена бинов, строки отчёта)
- [ ] Русский текст в выводе читается без кракозябр (кодировка UTF-8)

## Документация

- [ ] Раздел «Запуск» в README модуля исполнен буквально — команды скопированы и работают
- [ ] Точки останова указаны по классу и методу, без выдуманных номеров строк
- [ ] Mermaid-диаграммы отражают текущий код, а не план
- [ ] Ссылка «Дальше» указывает на существующий следующий модуль
- [ ] Статус модуля в корневом README соответствует реальности (✅/🚧/⬜)

## Структура проекта

- [ ] Новый модуль добавлен в `<modules>` корневого `pom.xml`
- [ ] Артефакт модуля следует соглашению (`kebab-case`), parent указан с `relativePath`
- [ ] Пример модуля ≤ ~200 строк кода; один модуль = одна идея
- [ ] Нет мусорных файлов: логи, `target/`, временные скрипты (всё лишнее удалено)

## Побочные эффекты

- [ ] `git status` показывает только файлы, относящиесяся к задаче
- [ ] Ни один существующий тест не изменён без причины
